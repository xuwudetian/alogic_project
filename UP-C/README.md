## 启动

**免安装启动：双击 `release/应急系统.exe`，或本目录的 `run_emergency_system.bat`。** 程序在 Windows 上无需另装 Python；需要 USB 转串口驱动。整个 `release` 目录可复制到其他电脑，配置保存在 EXE 同目录。

需要修改 Python 源码时，使用下面的方式运行（BAT 会优先打开已打包的 EXE）：

需要 Python 3.10 或更新版本（含 Tkinter）。在本目录运行：

```powershell
python -m pip install -r requirements.txt
python emergency_system.py
```

源码方式的依赖仅为 pyserial 和 Python 自带的 Tkinter。

1. A 板须烧录本次带 UART 遥测的固件。旧的 `NO_UART` 固件不会应答。
2. 使用板卡 USB 转串口接口连接电脑，在设备管理器确认实际 COM 口；蓝牙 COM 口不是 A 板。
3. 点击“刷新端口”，选择 A 板对应端口，再点击“连接 A 板”。参数固定为 **115200，8 数据位，无校验，1 停止位，无流控**。
4. 串口打开后先显示“等待数据”，收到有效状态帧后显示“在线”。默认每 500 ms 请求一次状态，可在“通信与设置”调整为 250 / 500 / 1000 / 2000 ms。无有效响应时显示超时次数和排查提示，不会生成测量数据。

引脚配置：FPGA `uart_rx=F12` 接 CH340 的 TXD，`uart_tx=D12` 接 CH340 的 RXD。外接转换器时使用 3.3 V TTL 电平并共地。对应约束位于 A 工程 `src/user_source/constraints_source/pin.adc`。

## 功能

- 四个工作页面：实时总览、数据记录、通信与设置、接入指南；深色界面、分色仪表、自适应滚动、实时状态栏。
- 光照原始值、光照传感器在线状态、声音 ADC 峰峰值；原始值不会被仪表量程截断。
- 车辆碰撞报警、声音报警、光照不足、设备异常提示。以 A 板返回的状态为准，碰撞提示优先。
- 最近 240 个采样点的趋势图：光照、声音独立坐标轴，自动缩放，声音高阈值标线。
- 设备快照：画面编号、显示就绪、亮度偏移、音量、状态码、错误码、UART 接收错误计数和协议版本。
- 事件日志、手动读取、曲线暂停/恢复、CSV 导出、连续写入 CSV、端口偏好记忆。
- 意外断线后每 3 秒尝试重连，匹配原端口与系统设备标识；不会自动选择其他 COM 口。手动“断开连接 / 停止重连”会停止重连。可在设置中关闭自动重连。
- 断开、超时或数据过期时清除实时读数和设备快照；恢复时重新开始曲线，避免跨断线连线。
- 数据记录页支持查看全部采样、报警采样、光照离线记录；显示最近 1,000 条匹配结果，CSV 导出包含整个缓存。
- 通信诊断显示请求数、有效采样、超时、坏帧、截断帧、收发字节和板端错误计数，支持导出 JSON 报告。
- 可选电脑报警提示音（默认关闭），仅对新出现的碰撞 / 声音报警提示；不影响板端蜂鸣器。
- F5 立即读取，Ctrl+E 导出采样；采样周期、自动重连、提示音与端口偏好会记忆。

“暂停曲线”只暂停绘图，报警监测与记录继续；恢复时从新的时间段开始绘图。导出采样最多保留最近 50,000 条，事件日志最多保留 1,000 条，窗口显示最近 100 条事件。长时间监测请用“开始记录 CSV”，每次有效采样都会立即写入文件，停止记录后文件关闭。CSV 使用 UTF-8 BOM，便于 Excel 打开中文字段。

## 读数和阈值

光照显示传感器原始值（0–65535），并非经过标定的 lux。声音显示 12 位 ADC 窗口峰峰值（0–4095），并非 dB SPL。光照离线时仪表显示“—”，导出仍包含“光照在线”字段以区分旧值。

板端当前阈值为：光照低于 160 触发暗环境确认，高于 320 恢复；声音高阈值 700、低阈值 350。上位机不修改阈值。声音报警还受板端连续窗口确认、有效采样、静音恢复和冷却机制控制；单个读数超过 700 不一定立即触发报警。具体逻辑保留在 `player_sensor_policy.v`。

## 协议 v2

帧：`A5 5A LEN SEQ CMD PAYLOAD CRC8`。CRC8 多项式 `0x07`，初值 0，无反转、无最终异或，覆盖 LEN 到 PAYLOAD；SEQ 为请求序号。多字节整数低字节在前。

请求：LEN=0，CMD=0x02。响应：LEN=19，CMD=0x82，PAYLOAD 为 `RESULT(1) + STATUS(16) + UART_ERRORS(2)`。RESULT=0 表示成功。

| STATUS 偏移 | 长度 | 含义 |
|---|---|---|
| 0–2 | 3 | `42 41 02`，设备标识 BA、协议版本 2 |
| 3 | 1 | bit7 暗环境；bit6 光照在线；bit5 声音报警来源；bit4 总报警；bit3 状态面板；bit2 目录；bit1 浏览；bit0 显示就绪 |
| 4–5 | 2 | 光照原始值 |
| 6–7 | 2 | 声音幅度，低 12 位有效 |
| 8 | 1 | 当前画面索引，从 0 开始 |
| 9 | 1 | 高 4 位模式、低 4 位物理开关 |
| 10 | 1 | 状态码 |
| 11 | 1 | 错误码 |
| 12 | 1 | 音频状态 |
| 13 | 1 | 高 4 位音量、低 4 位切换间隔 |
| 14–15 | 2 | 有符号亮度偏移 |

总报警包含声音报警：bit5=1 时显示声音场景；bit4=1 且 bit5=0 时显示碰撞场景。A 板有碰撞报警时会优先切换来源，因此上位机沿用相同优先级。

每次响应开始时锁存状态，整帧一致。错误计数包括接收帧错误、CRC 错误、请求字节超时，达到 65535 后饱和，复位后清零。发送期间忽略重复请求。生产固件只支持读取状态，不提供远程复位、清警或参数修改。Python 解析器还兼容此前的 45 字节 v1 状态格式。

## 检查与故障排查

```powershell
python -m py_compile emergency_system.py serial_protocol.py
python -m unittest discover -s tests -v
python tools/verify_fpga.py
```

单元测试使用隔离的合成数据，不打开物理串口、不保存为实际测量结果。`verify_fpga.py` 需要 PATH 中有 Icarus Verilog，运行 65 MHz UART 位级仿真，再将真实 TX 仿真字节交给生产 Python 解码器验证。

本次 Python / 位级仿真 / 构建日志在 `validation/continued_20261031`。已有 A、B 代码基线哈希保存在该目录，用于核对保护范围。实体接入探测单独记为 `hardware_probe.json`，不与仿真或真实传感器采样混用。

重新打包免安装程序：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.venv\Scripts\python.exe build_exe.py
```

生产程序不提供模拟设备模式，不会用合成数据冒充板卡数据。缓存为本次运行的数据，退出后不保留；需要持久记录时使用连续 CSV。

- 没有串口：检查 USB 数据线和 USB 转串口驱动；不要选择蓝牙串口。
- 提示端口被占用：关闭串口调试助手等占用该端口的软件。
- 串口打开但没有数据：确认烧录了带遥测的新固件、波特率为 115200、TX/RX 连接正确，A 板已完成复位。
- 光照显示离线：检查光照传感器连接；串口连接状态与传感器在线状态分别显示。
- 本次软件与 HDL 仿真不能替代实体板联调，烧录后应分别检查光照变化、声音触发、碰撞触发和断线状态。
